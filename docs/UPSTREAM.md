# Working with Upstream (Lakr233/vphone-cli)

Jailbreak Machine focuses on documentation quality, clear onboarding, and professional presentation.

The actual implementation lives upstream:

**https://github.com/Lakr233/vphone-cli**

### Recommended workflow

1. Read the guides in this repository first (especially Quick Start and Troubleshooting).
2. Clone the upstream repository (or this one if it later includes submodules/scripts).
3. Follow the build steps.
4. Use the variant recommendations and troubleshooting pages from Jailbreak Machine when you hit problems.

### Why this split exists

The original project is highly technical and moves fast with deep research patches.  
A clean documentation layer helps more people successfully use the tool without changing the upstream development model.
